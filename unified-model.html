How to label any function
1
Look at the declaration line before entering the body
If you see interface or type at file scope → Durable. Stop here, don't read body.
If the return type is JSX or you see DOM methods → Deliver. Stop here.
Otherwise continue to step 2.
2
Scan the body for MemReads, MemWrites, MemKills
Look for GET / SET / KILL keywords. Identify what memory location they touch (Params, Module, Browser, Remote...).
3
Apply the label rule
Only MemReads + return → Control
catch + return null → Control (gate not kill)
MemWrites present → Mutation
MemKills present → Sustain
4
Ask the dependency question
X — what data or files must exist? (usually Durable)
Y — what must have already run? (use Shift+F12 to find callers)
Z — what environment? (check API names: localStorage=browser, process.env=Node, import.meta.env=Vite)

Structural Signals (no body needed)
Durable — spotted at declaration
You see this before reading any function body. These are shapes, not actions.
interface LastReadState {
usfm: string;
chapter: number;
}
type WordToken = {
w: string;
morph?: string;
}
keyword interface or type at file scope = Durable. Always.
Deliver — spotted at output
The function's output is visual structure, not data. It produces something the browser renders.
return <div className="verse">
{text}
</div>
const el = document.createElement('div');
el.innerHTML = verse.zh;
return el;
JSX, createElement, innerHTML, appendChild = Deliver.
Environment Signals (for Z question)
fetch() → browser OR Node 18+ OR service worker
localStorage → browser tab ONLY — not Node, not service worker
caches.keys() → service worker ONLY
import.meta.env → Vite build ONLY — not raw Node
process.env → Node ONLY — not browser
document / DOM → browser tab ONLY

Key test
Would this function be irrelevant on a fresh install?

Yes → Sustain. It only matters after time has passed, things have accumulated, or something has degraded.

Sustain is a ring around all nodes — not a step in the chain.
